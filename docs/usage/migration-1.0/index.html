Migrating to the stable API

The stable package has no compatibility CSS or behavior adapter. Convert older markup before upgrading.

Semantic scope

Add data-mr to every subtree that should receive semantic/reset styling. Replace the transitional .mdl-scope root with[data-mr].

Package imports

Use markup-refine-lib/css and, when needed,markup-refine-lib/behaviors. Compatibility and direct historicaldist/* package imports are no longer exported.
