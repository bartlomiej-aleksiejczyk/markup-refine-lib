Native HTML reference

The markup-refine-lib/base entry refines native elements only inside adata-mr scope. This page summarizes that semantic surface so consumers do not need to inspect the CSS to discover which elements receive defaults.

CategoryNative elements / statesNotes
Document structurebody, main, p, footer, hrScoped spacing, surfaces, and typography.
Headingsh1–h6Semantic hierarchy is unchanged; CSS only supplies type/spacing.
Linksa, hover/focus/visitedUses the public link color tokens.
Listsul, olNative list semantics and markers remain intact.
Disclosuresdetails, summary, details[open]Native disclosure state remains the source of truth.
Formsform, fieldset, label, input, select, textarea, native buttonsIncludes disabled/focus, checkbox/radio, and file-selector presentation.
Tablestable, thead, tbody, tr, th, td, captionSmall-screen cells may expose authored data-label text.
Code/textpre, code, blockquote, kbd, small, sub, supNo JavaScript is required.
Images/figuresimg, figure, figcaptionImages remain responsive to the available inline size.
Embedded/mediaiframe, audio, video, mapBasic block sizing/presentation only.

Scope boundary

data-mr-unstyled stops semantic styling for a subtree; a nesteddata-mr explicitly re-enters the Markup Refine scope. SeeScoped semantic HTML for the isolation contract.
