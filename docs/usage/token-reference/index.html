Token reference

CSS custom properties are Markup Refine's public theming API. This reference is generated directly from the stable markup-refine-lib/css source import graph, so it lists tokens that are actually defined by the package rather than a hand-maintained duplicate.

Override tokens on the nearest application root or data-mr island. Component tokens inherit normally, so an override may be scoped to one subtree without changing other Markup Refine islands.

120 stable custom properties are currently defined.

Runtime-only custom properties

A behavior may write an internal custom property without defining it as a theme token. For example, Tooltip pin progress writes --mr-tooltip-pin-delay from the configured JavaScript pinDelay so CSS progress and behavior share one clock. Runtime-only properties are intentionally absent from the generated stable token inventory unless the stable CSS defines them as an author-overridable token.
