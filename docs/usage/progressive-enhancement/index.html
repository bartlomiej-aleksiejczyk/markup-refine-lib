Progressive enhancement

Behavior discovery uses only data-mr-*. Presentation classes are not runtime identity and the CSS remains useful when the JavaScript bundle is omitted.

Native and ARIA state first

  • Current-page links use aria-current="page".
  • Tabs use aria-selected, roving tabindex, and hidden panels.
  • The shell toggle uses aria-expanded and aria-controls.
  • Search uses native modal <dialog>.
