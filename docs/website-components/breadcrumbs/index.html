Breadcrumbs

Add mr-breadcrumbs to a semantic navigation root. The ordered list, list items, and links need no Markup Refine-specific part classes.

<nav class="mr-breadcrumbs" aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Home</a></li>
    <li><a href="/docs">Docs</a></li>
    <li aria-current="page">Components</li>
  </ol>
</nav>
